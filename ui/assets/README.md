# Buddy artwork

`buddy.png` is copied unchanged from the user's `BuddyV Game/public/mocker.png` asset at their request. It depicts the orange MockingIt character. No character-generation service was used.

The UI adds a small CSS idle movement and text reveal. There is no speech synthesis, audio playback, microphone access, or external character service. Reduced-motion settings disable both animations; a button reveals the whole message immediately.

The local BuddyV source game also contains a Blender/GLB character pipeline. This version uses its existing PNG to keep the review workspace small and dependable. Future 3D work should preserve provenance and verify any distribution terms before external publication.
